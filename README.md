# zaxnes_3dn

3D profiles (`.3dn`) for Zaxnes, the NES emulator with 3D rendering.

These profiles are kept apart from the Zaxnes code: they are not covered by its GPL license but
by **CC BY-NC-ND 4.0** (see [LICENSE](LICENSE)). Zaxnes ships them alongside its binaries as
separate files.

## Profiles

| File | Game |
| --- | --- |
| `Faxanadu.3dn` | Faxanadu (USA) |
| `Metal Force.3dn` | Metal Force (Korea) |

## Use

Copy a `.3dn` file into the Zaxnes profiles folder, then pick it for the game.
